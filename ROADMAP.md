# Roadmap

Shaped features the project has committed to building. Items here are ready for an agent to pick up — for unshaped exploration see `IDEAS.md`; for items decided-not-now see `FOLLOW_UPS.md`.

A feature gets phases only when it's big enough that shipping in one go would be unmanageable. Each phase must be deployable on its own — if Phase 1 doesn't land something useful in production, it's just a step list, not a phase.
